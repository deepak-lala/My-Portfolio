# Deepak Gupta — 3D Developer Portfolio

This repository contains my personal 3D developer portfolio website built with React, TypeScript, and Three.js.

- Author: Deepak Gupta
- Repository: https://github.com/deepak-lala/My-Portfolio

## Tech Stack

- React
- TypeScript
- Three.js / WebGL
- GSAP

## Getting started

1. Clone your repo:

```bash
git clone https://github.com/deepak-lala/My-Portfolio.git
cd My-Portfolio
```

2. Install dependencies:

```bash
npm install
```

3. Run locally:

```bash
npm run dev
```

4. Build for production:

```bash
npm run build
```

## Customize

- Update the hero section with your name and intro.
- Replace or update projects and assets under `public/` and `src/`.
- Update social links in the codebase to your profiles.
